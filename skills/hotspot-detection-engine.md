# 热点发现引擎 Skill

用于实时发现热点事件、分析热点趋势、生成数据驱动的热点报告。

## 何时使用

使用此 Skill 当您需要：
- 发现当前最热门的话题和事件
- 分析热点在不同时间段的趋势
- 跨多个信息源（Web、Twitter、知乎等）比较热点热度
- 按分类查看热点分布（技术、金融、娱乐等）
- 识别新兴趋势和高速增长的话题
- 生成周期性的热点分析报告

## 工作流

### 1. 获取实时热点列表
```bash
GET /hotspots
# 返回最新的热点列表（按时间倒序）
# 每条热点包含：
#   - 标题和描述
#   - 热度评分 (0-10)
#   - 趋势方向（增长%）
#   - 数据来源
#   - 相关关键词
```

### 2. 按分类浏览热点
```bash
GET /hotspots/category/{category}
# 按内容分类浏览热点
# 支持的分类: tech, finance, entertainment, sports, general
```

### 3. 按来源分析热点
```bash
GET /hotspots/source/{source}
# 查看特定来源的热点
# 来源: Web, Twitter, Zhihu, Xiaohongshu
```

## 热点数据结构

每个热点事件包含以下信息：

```json
{
  "id": "唯一标识",
  "title": "热点标题",
  "description": "事件描述（限制在500字以内）",
  "source": "Web|Twitter|Zhihu|Xiaohongshu",
  "category": "自动识别的分类",
  "score": 7.5,
  "trend": 25,
  "url": "原始内容链接",
  "timestamp": "2026-08-15T14:30:00Z",
  "keywords": ["关键词1", "关键词2"]
}
```

## 关键指标解释

| 指标 | 范围 | 含义 |
|-----|-----|-----|
| **score** (热度评分) | 0-10 | 越高越热。≥7 为高热度热点 |
| **trend** (趋势方向) | -100 ~ +100 | 正数表示上升，负数表示下降 |
| **source** (数据来源) | 见上 | 该热点最初发现的平台 |
| **category** (内容分类) | 多种 | AI 自动识别，用于分类展示 |

## 常见问题

### Q: 热点评分如何计算？
A: 结合以下因素：
   - 信息的转发/分享量
   - AI 识别的相关性
   - 时间衰减（越新越高）
   - 平台权重差异

### Q: 如何判断是否为虚假热点？
A: 系统会检查：
   - 内容的真实性
   - 来源的可信度
   - 是否为营销内容
   - 转发链条是否自然

### Q: 热点数据多久更新一次？
A: 后台每 15 分钟扫描一次，您可以手动刷新立即获取最新数据。
