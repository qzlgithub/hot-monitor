# 📂 开发记忆（项目记忆备份）

> 本文件夹用于在项目**封存期间**备份 AI 助手的「记忆」，确保后续能**无缝衔接**继续开发。

## 为什么建这个文件夹

AI 助手的记忆本身是持久的（见下「记忆系统说明」），但为了 **100% 双保险**，把关键记忆复制到项目内，即使记忆系统出问题也不会丢。

## 文件说明

| 文件 | 内容 |
|---|---|
| `workflow_preferences.md` | **用户工作偏好**：Git 操作方式 / 方案确认流程 / 前端 UI 规范（ui-ux-pro-max + Aceternity） |
| `hot_monitor_project.md` | **项目开发记忆**：架构 / 数据源 / fetcher 分层 / 藏宝阁监控 / 捡漏雷达 / 走势图 / 踩坑 / 待办 / 完整开发史 |

## 记忆系统说明（为什么记忆不会消失）

- **用户记忆** `/memories/`（工作偏好）→ **全局记忆**，跨所有项目/会话持久，与单个项目无关
- **仓库记忆** `/memories/repo/`（项目记忆）→ **仓库级**，存在当前工作区内，只要项目文件夹保留就还在
- 因此项目封存**不会导致记忆消失**；此处备份是额外的保险

## 如何恢复（下次继续项目）

1. 打开项目，新会话粘贴 `OPENING_PROMPT.md` 的提示词（会引导 AI 读取记忆）
2. 如记忆系统正常，AI 会自动读取 `/memories/` 下的记忆
3. 如记忆异常/换环境，直接把本文件夹两个文件的内容贴给 AI，或恢复回记忆路径：
   - 用户记忆 → `/memories/workflow_preferences.md`
   - 仓库记忆 → `/memories/repo/hot_monitor_project.md`
